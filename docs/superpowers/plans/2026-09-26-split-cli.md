# Split the CLI into a package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the 4,266-line `scripts/precedent.py` into a thin PEP 723 entry script plus a `precedent_cli` package beside it. It must stay runnable with `uv run`, ship through both install channels, and be documented for people who don't use uv.

**Architecture:** The CLI moves into the `precedent` skill's directory, `adapters/claude/skills/precedent/scripts/`. ACR ships a `scripts` artifact as exactly one regular file, but ships a skill as its whole directory (ACR `docs/package-manifest.md`, "Artifact Model"). The Claude Code plugin channel copies the whole repository (ADR 0007). Python puts the running script's resolved directory on `sys.path`, so `import precedent_cli` works with no install step. The split itself is mechanical: an AST-driven one-off script slices the file and writes each module's imports, and a second one-off script applies the edits it can't infer.

**Tech Stack:** Python 3.12+, `graphdblite`, `uv` (PEP 723 inline metadata), bash + PowerShell hooks, GitHub Actions on ubuntu/macos/windows.

**Spec:** No separate spec. The requirement is the user's request: "split one huge python file into multiple still runnable via uv run. Add instructions on how to use it with default python/pip/whatever". The prior decision it implements is precedent `#split-into-a-sibling-package-behind-a-thin-pep-7-1790448065`. The layout choice is recorded in ADR 0010 (written in Task 1).

## Global Constraints

- Work on branch `next` (unreleased work integrates on `next`; `main` is the release).
- `requires-python = ">=3.12"`; the only runtime dependency is `graphdblite`.
- No install step, no `pyproject.toml`, no committed venv: `uv run <entry>` stays the primary way to run it (precedent: "Keep uv run + PEP 723, no durable venv").
- Entry script: `adapters/claude/skills/precedent/scripts/precedent.py`. Package: `adapters/claude/skills/precedent/scripts/precedent_cli/`.
- Behaviour is unchanged: CLI output for the same store is byte-identical before and after the split (Task 2 diffs it).
- Must run on Linux, macOS and Windows; CI runs all three.
- Read and write files with `encoding="utf-8"` (Windows console codepage breaks the default).
- Historical documents (`docs/adr/0001`–`0009`, `docs/superpowers/plans/*` other than this one, `docs/superpowers/specs/*`, `docs/spec-*.md`, `docs/carried-forward-from-plan-a.md`) stay as written. They describe what was true then.

## Review Focus

1. **Run from another directory, or through a symlink.** Manual installs symlink the skill (or the script) into `~/.claude/skills`, and agents run the CLI from the project directory. Expected: the package still imports. Pinned by `_check_entry_point` (Task 2).
2. **An ACR install gets the package, not just the entry script.** Expected: the realized `acr__…__precedent/scripts/` contains `precedent_cli/` and the hook's brief appears. Pinned by the ACR layout in `tests/hook-finds-cli.sh` (Task 1).
3. **The Windows hook finds the CLI at its new path.** Today's CI step passes even when the hook can't find the CLI: an empty store prints nothing either way. Expected: a seeded store makes the hook print a brief. Pinned by the seeded pwsh CI step (Task 1).
4. **Plain `python` without graphdblite installed.** This is the new audience the docs invite. Expected: a store command says how to install the engine, not a `ModuleNotFoundError` traceback. Pinned by `_check_missing_engine` (Task 3).
5. **The banner names the entry script, not a module file.** `standing-orders` used `__file__`, which after the split would point inside the package. Expected: it prints `…/scripts/precedent.py`, an existing file. Pinned by `_check_standing_orders` (Task 2 edit) and `_check_entry_point`.

- [ ] **Step 9: Write ADR 0010**

Create `docs/adr/0010-the-cli-lives-in-the-skill-tree.md`:

```markdown
# The CLI lives in the `precedent` skill's directory

The CLI outgrew one file, and the split puts a `precedent_cli` package beside a
thin PEP 723 entry script; Python adds the script's directory to `sys.path`, so
nothing is installed. That only works where the package travels with the script.

ACR ships a `scripts` artifact as exactly one regular file (ACR
`docs/package-manifest.md`, "Artifact Model"), so a package beside
`scripts/precedent.py` would be missing from every ACR install — Codex and
Cursor included — and the hook would fail closed, silently. A skill artifact is
its whole directory. So the entry script and the package live in
`adapters/claude/skills/precedent/scripts/`, and the `precedent-cli` script
artifact is gone from `agent-plugin.yaml`.

The plugin channel is unaffected in kind: it copies the repository (ADR 0007),
and the hook resolves the CLI relative to itself, now at
`../skills/precedent/scripts/precedent.py`.

## Rejected

- **Keep `scripts/`, drop ACR.** Least path churn; loses the only channel that
  reaches Codex and Cursor.
- **Keep one file.** The file was 4,266 lines.

## Consequences

Anyone who invoked `scripts/precedent.py` from a clone by hand must use the new
path. ADR 0007's statement of the CLI's location is historical from here on.
```

`$B/split.py`:

```python
"""One-off: slice the monolith into the precedent_cli package.

Usage: python3 split.py <path/to/precedent.py> [--dry-run]
Writes precedent_cli/ beside it, with each module's imports computed from the
names it uses. Prints the module graph; exits 1 on an import cycle.
"""
import ast
import pathlib
import sys

SRC = pathlib.Path(sys.argv[1])
DRY = "--dry-run" in sys.argv
PKG = SRC.parent / "precedent_cli"

# First top-level name of each module, in file order.
STARTS = {"DEFAULT_HOME": "core", "NOISE": "projects", "write_decision": "writing",
          "worth_backfilling": "reading", "cmd_tag": "maintain", "mark_graph_format": "replay",
          "_ensure_removable": "admin",
          "_check_helpers": "selftest/checks_store", "build_parser": "cli"}
# Selftest functions, regrouped by what they exercise.
SELFTEST = {
    "selftest/checks_store": [
        "_check_helpers", "_check_standing_orders", "_check_relocate", "_check_export",
        "_check_concurrent_writers", "_check_reader_isolation", "_check_lock_modes",
        "_check_journal", "_check_graph_format"],
    "selftest/checks_graph": [
        "_check_projects", "_check_decisions", "_check_amend", "_check_verdicts",
        "_check_maintain", "_check_maintain_hints", "_check_missing_project", "_check_drift"],
    "selftest/checks_identity": [
        "_git", "_git_repo", "_check_detect_project", "_check_worktrees", "_check_identity",
        "_check_identity_gaps", "_check_rekey", "_check_settle", "_check_merge_project",
        "_check_merge_replay", "_check_merged_into_portable", "_check_remote_changed",
        "_check_merge_legacy_clash", "_check_portable_replay"],
    "selftest/__init__": ["cmd_selftest"],
}
SELFTEST_OF = {n: m for m, ns in SELFTEST.items() for n in ns}
# Edges that would close an import cycle; fixups.py imports these at call time.
LAZY = {("core", "replay"), ("cli", "selftest/__init__")}

text = SRC.read_text(encoding="utf-8")
lines = text.splitlines(keepends=True)
tree = ast.parse(text)
doc = ast.get_docstring(tree, clean=False)


def names_defined(node):
    if isinstance(node, (ast.FunctionDef, ast.ClassDef)):
        return [node.name]
    if isinstance(node, (ast.Assign, ast.AnnAssign)):
        targets = node.targets if isinstance(node, ast.Assign) else [node.target]
        return [t.id for t in targets if isinstance(t, ast.Name)]
    return []


def used_names(src: str) -> set[str]:
    """Free names per top-level statement: loads minus what that statement binds."""
    used = set()
    for top in ast.parse(src).body:
        bound = {a.arg for a in ast.walk(top) if isinstance(a, ast.arg)}
        bound |= {n.id for n in ast.walk(top)
                  if isinstance(n, ast.Name) and isinstance(n.ctx, ast.Store)}
        bound |= {(a.asname or a.name).split(".")[0] for n in ast.walk(top)
                  if isinstance(n, (ast.Import, ast.ImportFrom)) for a in n.names}
        if isinstance(top, (ast.FunctionDef, ast.ClassDef)):
            bound.discard(top.name)
        used |= {n.id for n in ast.walk(top)
                 if isinstance(n, ast.Name) and isinstance(n.ctx, ast.Load)} - bound
    return used


chunks: dict[str, list[str]] = {}
owner: dict[str, str] = {}
imports_src = []
module = None
prev_end = 0
for node in tree.body:
    # Each chunk carries the comments above it, so section banners travel too.
    seg = "".join(lines[prev_end:node.end_lineno])
    prev_end = node.end_lineno
    if isinstance(node, (ast.Import, ast.ImportFrom)):
        if not (isinstance(node, ast.ImportFrom) and node.module == "__future__"):
            imports_src.append((ast.get_source_segment(text, node),
                                {(a.asname or a.name).split(".")[0] for a in node.names}))
        continue
    if isinstance(node, (ast.Expr, ast.If)):
        continue                     # the module docstring, and `if __name__ == ...`
    names = names_defined(node)
    if names and names[0] in STARTS:
        module = STARTS[names[0]]
    target = SELFTEST_OF.get(names[0], module) if names else module
    if module and module.startswith("selftest") and names and names[0] not in SELFTEST_OF:
        sys.exit(f"selftest function {names[0]} is not assigned to a submodule")
    chunks.setdefault(target, []).append(seg if chunks.get(target) else seg.lstrip("\n"))
    for n in names:
        owner[n] = target

deps: dict[str, dict[str, set[str]]] = {}
for mod, segs in chunks.items():
    mine = {n for n, m in owner.items() if m == mod}
    for n in used_names("".join(segs)) - mine:
        if n in owner:
            deps.setdefault(mod, {}).setdefault(owner[n], set()).add(n)


def rel(frm: str, to: str) -> str:
    if "/" in frm and to.rsplit("/", 1)[0] == frm.rsplit("/", 1)[0]:
        return "." + to.rsplit("/", 1)[1]                      # sibling in selftest/
    return "." * (frm.count("/") + 1) + to.replace("/", ".").removesuffix(".__init__")


out = {}
for mod, segs in chunks.items():
    free = used_names("".join(segs))
    head = ["from __future__ import annotations\n\n",
            *[src + "\n" for src, binds in imports_src if binds & free], "\n"]
    for to, ns in sorted(deps.get(mod, {}).items()):
        if (mod, to) in LAZY:
            print(f"LAZY {mod} -> {to}: {sorted(ns)}")
            continue
        head.append(f"from {rel(mod, to)} import {', '.join(sorted(ns))}\n")
    out[mod] = "".join(head) + "\n\n" + "".join(segs).rstrip() + "\n"

graph = {m: {t for t in d if (m, t) not in LAZY} for m, d in deps.items()}
cycles = []


def walk(n, stack):
    for t in graph.get(n, ()):
        if t in stack:
            cycles.append(" -> ".join(stack[stack.index(t):] + [t]))
        else:
            walk(t, stack + [t])


for m in graph:
    walk(m, [m])
print("dependency graph:")
for m in sorted(graph):
    print(f"  {m} -> {', '.join(sorted(graph[m]))}")
for c in sorted(set(cycles)):
    print("CYCLE:", c)
if cycles:
    sys.exit(1)
if DRY:
    sys.exit(0)

(PKG / "selftest").mkdir(parents=True, exist_ok=True)
(PKG / "__init__.py").write_text(f'"""{doc}"""\n', encoding="utf-8")
for mod, src in out.items():
    (PKG / f"{mod}.py").write_text(src, encoding="utf-8")
```

`$B/fixups.py`:

```python
"""One-off: the edits split.py cannot infer. Run from the scripts/ directory."""
import pathlib

P = pathlib.Path("precedent_cli")


def sub(f, old, new, count=1):
    p = P / f
    s = p.read_text(encoding="utf-8")
    assert s.count(old) == count, (f, old, s.count(old))
    p.write_text(s.replace(old, new), encoding="utf-8")


# core: the entry script's path, and Store's lazy imports of the replay code.
sub("core.py", "DEFAULT_HOME = ",
    'CLI = pathlib.Path(__file__).resolve().parent.parent / "precedent.py"\nDEFAULT_HOME = ')
sub("core.py", "        n, skipped = replay_journal(self)",
    "        from .replay import replay_journal  # lazy: replay imports core\n"
    "        n, skipped = replay_journal(self)", 2)
sub("core.py", "            mark_graph_format(self)",
    "            from .replay import mark_graph_format  # lazy: replay imports core\n"
    "            mark_graph_format(self)")
```

```python
def _check_entry_point() -> None:
    """The entry script imports its package from any cwd and through a symlink.

    Python puts the *resolved* script directory on sys.path, which is the whole
    reason the split needs no install step. Manual installs symlink the skill
    or the script, and agents run it from the project directory, so both must
    work. standing-orders needs no Store, so this costs no engine start.
    """
    import tempfile

    with tempfile.TemporaryDirectory() as tmp:
        targets = [CLI]
        link = pathlib.Path(tmp) / "precedent-link.py"
        try:
            link.symlink_to(CLI)
            targets.append(link)
        except OSError:
            pass  # ponytail: Windows without Developer Mode cannot symlink; the cwd case still runs
        for target in targets:
            r = subprocess.run([sys.executable, str(target), "standing-orders"],
                               cwd=tmp, capture_output=True, text=True, encoding="utf-8",
                               env={**os.environ, "PYTHONUTF8": "1"})
            assert r.returncode == 0, f"{target} failed from {tmp}: {r.stderr}"
            assert str(CLI) in r.stdout, f"{target} must name the entry script {CLI}"
```
