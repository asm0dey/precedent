# Open Issues #33, #34, #35 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the three open GitHub issues: a stale uv environment silently disabling the hook (#33), a false warning and an ambiguous journal line when amending a principle (#34), and subagents never receiving the brief (#35).

**Architecture:** #34 is a local change in `cmd_principle`. #33 is a version floor in the PEP 723 header plus a one-line failure notice in both hook twins (`session-start.sh`, `session-start.ps1`). #35 adds a `subagent-start` CLI command that reads the SubagentStart hook JSON on stdin and prints `hookSpecificOutput.additionalContext`; `session-start.sh --subagent` reuses its existing CLI lookup and hands off to it.

**Tech Stack:** Python 3.12 (PEP 723 script run by `uv run`), graphdblite, bash, PowerShell, Claude Code plugin hooks.

**Spec:** The issue bodies are the spec: `gh issue view 33|34|35 --json body -q .body`. Hook contract (checked 2026-11-04 against https://code.claude.com/docs/en/hooks): SubagentStart matcher = agent type; every hook gets the common field `cwd`; subagent hooks also get `agent_type`; context is added only via `{"hookSpecificOutput": {"hookEventName": "SubagentStart", "additionalContext": "..."}}` (plain stdout is NOT context); it cannot block.

## Global Constraints

- Branch off `next`, PR into `next` (precedent: unreleased work integrates on `next`; `main` is the release). One commit per task. Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Support Windows: `session-start.ps1` is the twin of `session-start.sh` and "both must stay behaviourally identical". Any hook behaviour change lands in both.
- Hooks always exit 0. A session or subagent must never be blocked by precedent.
- Tests never touch the real store or `~/.claude`: throwaway `--home`/`PRECEDENT_HOME`, and `CLAUDE_CONFIG_DIR` inside the test's temp dir (see `tests/hook-finds-cli.sh`).
- Selftest leaves the node count unchanged; checks that journal use their own `tempfile.TemporaryDirectory()` store.
- The failure notice is exactly one line: `PRECEDENT unavailable: <reason> — rerun: uv run "<cli>" brief --project .` where `<reason>` is the first non-empty stderr/exception line, or `brief timed out after 20s` on timeout (GNU `timeout` exit 124).
- graphdblite floor: `graphdblite>=0.2` (the release that writes schema 2).

## Review Focus

1. `subagent-start` with empty or malformed stdin → prints nothing, exits 0, no traceback. Test in Task 3.
2. Brief times out in the hook (exit 124, empty stderr) → notice says `brief timed out after 20s`, orders still print. Test in Task 2.
3. SubagentStart input without `cwd` → falls back to the process working directory. Test in Task 3.
4. Amending a principle that never had topics, still without `--topic` → the warning still prints (it is true). Test in Task 1.
5. The subagent path must not delete or create the main session's statusline marker. Test in Task 3.
